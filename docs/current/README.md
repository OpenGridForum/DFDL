# Current documents

The DFDL specification is no longer kept here. It is written in AsciiDoc under
[`spec/`](https://github.com/OpenGridForum/DFDL/tree/master/spec), and its Word
editions are in [`docs/archive/Archive-2026/`](../archive/Archive-2026/).

Two pages from those editions stay here on purpose, because public links point
at them: `gwdrp-dfdl-v1.0.8-GFD-R-P.240.htm` and
`gwdrp-dfdl-v1.0.9-GFD-R-P.240.htm`, each with its `_files` folder. The v1.0.9
page is the current published edition of GFD.240, updated June 2023; the v1.0.8
page is the February 2021 edition it superseded.

Everything else here is unchanged: the experimental features index, the
experience documents, the TDML draft, the tutorials and the diagrams.
